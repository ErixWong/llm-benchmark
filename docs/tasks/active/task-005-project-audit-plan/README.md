# Task-005: 全项目审计计划

## 目标

为当前项目制定一套可执行、可追踪的代码审计计划，本次审计范围限定为 `src/`、`tests/`、`scripts/`，重点覆盖核心计算、并发调度、报告输出、测试质量和脚本维护性风险。

## 审计对象

- `src/` 源码模块
- `tests/` 测试用例
- `scripts/` 辅助脚本

## 审计目标

1. 确认 `src/` 当前实现是否与 benchmark 目标一致
2. 识别计算不合理、口径不一致和统计误导问题
3. 识别设计不合理、职责漂移和死代码问题
4. 识别 `tests/` 覆盖缺口与回归风险
5. 识别 `scripts/` 与当前代码结构脱节的维护性问题
6. 输出修复优先级和执行顺序

## 审计阶段

1. `src/` 项目目标与运行路径盘点
2. 核心 benchmark 计算与并发行为审计
3. 报告生成与结果解释审计
4. `tests/` 覆盖与回归能力审计
5. `scripts/` 维护性与一致性审计
6. 风险汇总与修复路线图

## 输出物

- 审计问题清单（按严重度分级）
- 口径说明与风险解释
- 修复建议与优先级排序
- 必要时的任务拆分建议
